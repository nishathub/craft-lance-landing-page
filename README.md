# Craft-Lance Landing Page

🚀 **Live Demo:** [View Site](https://nishathub.github.io/craft-lance-landing-page)

## 📌 Overview

The **Craft-Lance Landing Page** is a fully responsive, clean, and modern business analytics-themed landing page built entirely with **HTML** and **SCSS**. This project serves as a **front-end design demo** to showcase layout skills, responsive design principles, and styling capabilities using SCSS.

> ⚠️ Note: This is a static demo page — none of the buttons or navigation links are functional. The focus is purely on layout, design, and responsiveness.

---

## 🛠️ Built With

- HTML5
- SCSS (CSS Preprocessor)
- Responsive Design (Media Queries & Flex/Grid)

---

## 🎯 Features

- ⚡ Clean and structured HTML/SCSS codebase
- 📱 Fully responsive across desktop, tablet, and mobile devices
- 🧩 Component-based layout structure (e.g., hero, pricing, features, footer)
- 🎨 SCSS variables and nesting for maintainable styling
- 💡 Minimal external dependencies

---

## 🧪 Purpose

This project was created as a **practice landing page** to improve front-end development skills. It demonstrates proficiency in:

- SCSS structuring and modularization
- Responsive web design
- Clean HTML/CSS architecture

---

## 📌 Note for Reviewers

- This project is not connected to a backend.
- It does not include interactivity or JavaScript functionality.
- Designed for design/showcase purposes only.
